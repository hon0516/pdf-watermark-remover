# Changelog

## 0.1.0 - 2026-09-23

首次公开发布。包含本地 PDF 网页工具、可识别裁剪式 Pattern 平铺水印的候选确认与导出，并明确说明当前格式限制。

Initial public release. Includes the local PDF web tool, candidate review and export for recognizable clipped tiled Pattern watermarks, and documentation of current format limitations.

- First public release of the local PDF watermark remover.
- Adds candidate review and export for recognizable clipped, tiled Pattern watermark blocks.
- Keeps PDF processing local and writes output as a new file.
- Documents current format limitations; scanned, ordinary text/image, and other watermark encodings are not supported yet.
